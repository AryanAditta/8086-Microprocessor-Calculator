# 8086 Microprocessor Calculator

**Assembly-language calculator implemented for the Intel 8086 microprocessor.**

The project demonstrates low-level arithmetic control, keyboard input, branching and DOS interrupt-based console I/O in an 8086 environment.

## Implemented Operations

- Addition
- Subtraction, including negative-result handling
- Multiplication
- Division with quotient and remainder output
- Division-by-zero handling

## Implementation Notes

- Written in **8086 assembly language**.
- Uses DOS interrupt services for keyboard input and console output.
- Organizes arithmetic operations into dedicated procedures.
- Accepts menu-driven user selection for the four arithmetic operations.

## Running the Project

1. Open `Microprocessor Project code.asm` in an 8086-compatible assembler/emulator such as **emu8086**.
2. Assemble and run the program.
3. Select an arithmetic operation from the menu and enter the requested operands.
